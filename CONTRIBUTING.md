Contributing
============

Contributions are welcome.

By submitting a pull request, issue, patch, or other contribution to this
repository, you agree that your contribution is provided under the same license
as the project: GPL-2.0-or-later.

Please only submit code, documentation, assets, or other materials that you
have the right to contribute.

Good contributions include:

- bug fixes
- OBS compatibility improvements
- Whisper/transcription improvements
- filename formatting features
- documentation improvements
- security fixes
- platform-specific fixes

Please do not submit code that intentionally adds malware, hidden telemetry,
credential collection, destructive behavior, or hidden network activity.
