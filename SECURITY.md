Security Policy
===============

Official SayClip releases are published only through the official repository:

https://github.com/aitoolmakerofficial/obs-sayclip

Please be careful with unofficial builds, mirrors, installers, or modified
versions. AI Toolmaker (AI Toolmaker Official) cannot verify or guarantee the
safety of unofficial distributions.

Reporting Security Issues
-------------------------

If you discover a security issue in SayClip, please report it by opening a
private security advisory on GitHub or by contacting:

https://github.com/aitoolmakerofficial/obs-sayclip/security/advisories

When reporting an unofficial or suspicious copy, include:

- the URL where it was found;
- the file name and version, if shown;
- hashes of the downloaded file, if available;
- screenshots or archive contents that show the impersonation or modification.

Please do not publicly disclose serious security issues before they can be
reviewed.

Do not run suspicious builds just to test them.
